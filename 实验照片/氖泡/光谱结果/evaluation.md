# 氖泡光谱结果评估

## 总评

分立氖谱识别成功，波长轴整体可信；分辨率对本科光盘/光栅装置属于**中上**，能分开多数红区氖线，但未到精密光谱仪水平。

## 1. 谱线位置准确度（波长标定）

| 指标 | 数值 |
|---|---|
| 匹配谱线数 | 18 |
| 残差均值 | -0.000 nm |
| **RMS 残差** | **0.356 nm** |
| 中位\|残差\| | 0.251 nm |
| 最大\|残差\| | 0.773 nm（540.1 nm 绿线） |
| \|残差\|<0.5 nm | 16/18（89%） |
| \|残差\|<1.0 nm | 18/18 |

**解读：** RMS≈0.36 nm 表示用线性色散标定后，测得峰位与 Ne 标准波长平均偏差约三分之一纳米。对手机/相机拍照的衍射光谱来说，这是**良好**的波长准确度。绿线 540 nm 残差偏大（+0.77 nm），可能来自：色散随波长不完全线性、镜头色差、或绿线较弱峰值定位误差。

## 2. 分辨率

仪器分辨率用窄线的 **FWHM** 估计 \(\Delta\lambda\)，分辨本领 \(R=\lambda/\Delta\lambda\)。

| 指标 | 数值 |
|---|---|
| 最佳 FWHM（绿线 540） | **1.24 nm** |
| 最佳 \(R\) | **≈437** |
| 较干净线（FWHM<5）中位 FWHM | 2.65 nm |
| 较干净线中位 \(R\) | ≈234 |

**解读：**
- 绿线最锐（≈1.2 nm）：该波长处分辨率最好，\(R\sim 440\)。
- 多数未饱和红线 FWHM≈2–3 nm，\(R\sim 200\sim 300\)。
- 部分亮线 FWHM>10 nm：不是真分辨率差，而是**过曝/相邻线重叠**把峰拉宽，应忽略。

对比：文献中较好的 DVD 纸板仪可分开 Hg 577/579（间距 2 nm）；你们氖灯上 667.8/671.7（间距 3.9 nm）已清楚分开，640.2/638.3（间距 1.9 nm）也能分开——与「能处理 ~2 nm 量级双线」一致。

## 3. 综合结论

| 维度 | 评价 |
|---|---|
| 谱线识别 | 优（18 条 Ne I） |
| 波长准确度 | 良（RMS 0.36 nm） |
| 分辨率 | 中上（最佳 Δλ≈1.2 nm，典型 2–3 nm） |
| 主要短板 | 亮线饱和；线性色散在绿端略偏；未做狭缝/准直系统优化对比 |

若要再提升：降低曝光避免黄线饱和、加准直与更窄狭缝、用二次多项式色散标定压低绿端残差。
