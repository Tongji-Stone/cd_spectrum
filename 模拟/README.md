# 光盘反射光栅模拟

打开 `index.html` 即可在浏览器中使用，不需要安装 Python 包或联网。

页面并列比较三种刻线几何：

1. 平行划线：理想平面反射光栅基准。
2. 同心圆划线：刻线法线沿光盘半径变化。
3. 螺线划线：阿基米德螺线，轨距为相邻螺旋圈的径向间隔。

可以调整光栅轨距、入射角、光斑大小和位置、狭缝宽度、光束发散、光源谱型及衍射级次。页面顶部的侧视图显示光源、狭缝、准直镜、光盘、零级镜面反射和按波长分开的一级衍射方向；下面三幅图使用相同角度坐标范围，展示探测器正面看到的二维光谱。颜色直接表示波长；中心截面 FWHM 是图像中水平中心截线的半高全宽。

## 计算近似

对每个照明位置，使用局部反射光栅关系

\[
\mathbf u_{out}=\mathbf u_{in}-m\lambda\,\nabla\psi,
\]

其中 `m` 为衍射级次，`u` 是光线在盘面内的方向余弦；三个模型的刻线相位为

\[
\psi_{平行}=x/d,\qquad
\psi_{圆环}=r/d,\qquad
\psi_{螺线}=r/d-\theta/(2\pi).
\]

有限照明区域通过 1800 个黄金角分布的盘面采样点表示，避免规则网格形成的点阵伪影。白光按 2 nm 间隔积分，每条光线按亚像素位置分配到相邻像素；随后统一加入有限光斑口径、入射发散和狭缝角宽造成的模糊。狭缝角宽暂按 100 mm 准直镜估算，约为 `狭缝宽度 / 准直焦距`。不同波长在线性 RGB 中叠加，最后统一曝光和显示伽马，因此图像表现为连续彩带，而不是离散波长点阵。

螺线刻线的局部法线包含切向分量，因此可与同心圆模型直接比较；页面会显示其局部修正量 `d/(2πR)`。

## 使用边界

这是用于比较模型简化误差趋势的标量、局部光栅近似。白光采用等能量光谱，以便单独观察几何效应。模型没有加入真实坑槽剖面、偏振、反射率、染料吸收、盘片翘曲及相干衍射效率，因此绝对亮度、真实光栅效率和实物谱线宽度不能直接由它确定。要和实验定量对照，需要加入实测光源光谱、入射光分布、光斑形状、实际轨距及样品误差。
