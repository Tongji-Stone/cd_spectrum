# 光盘记录点对衍射线宽的影响

这个计算研究两件事：沿着轨道把连续槽切成短段，会不会让分光方向上的谱线变宽？相邻轨道的记录点对齐或错开，又会把光送到哪里？

## 运行与结果

需要 Python、NumPy 2 和 Matplotlib。从仓库根目录运行：

```powershell
python '模拟/记录点衍射/simulate.py'
```

脚本默认输出 [DVD 图](结果/DVD.png)、[DVD 数据](结果/DVD.csv)、[CD 图](结果/CD.png)和 [CD 数据](结果/CD.csv)。可通过 `--help` 查看照明尺寸、入射角、波长、探测角窗口和随机种子选项。默认取盘面上约 1.00 mm（径向）× 0.25 mm（切向）的均匀矩形光斑、589 nm 单色光、65° 入射角，比较径向 +1 级，并沿切向方向余弦对应的 ±1° 窗口积分。DVD 取轨距 0.74 μm，CD 取 1.60 μm。图中给出的最短记录段 0.40 μm 和 0.83 μm 分别作为 3T，用于设置沿轨采样尺度。

## DVD 数值结果

| 图案 | 记录点占比 | 尺度等效 FWHM（nm） | 中心峰强度 / 连续槽 |
| --- | ---: | ---: | ---: |
| 连续槽 | 100% | 0.3862 | 100% |
| 重复 0101，轨间对齐 | 50% | 0.3862 | 25.0% |
| 重复 0100，轨间对齐 | 25% | 0.3862 | 6.25% |
| 重复 0101，相邻轨随机错相 | 50% | 0.3862 | 25.0% |
| 独立随机 3T–11T 坑、台交替 | 约 50% | 0.3860 | 25.02% |
| 径向只保留一半轨道 | 约 50% | 0.7730 | 24.96% |

FWHM 来自 ±1° 积分后的径向曲线，用局部色散率换算成等效波长宽度。中心峰强度在两个方向都取主级次中心。CSV 中的 `accepted_core_energy_relative` 是对同一固定窗口积分的相对值，径向边界取连续槽的两侧第一暗纹，切向边界取接收角。半孔径的主瓣更宽，固定窗口内能量比分布两维的中心峰比例更高，这两个指标的定义不同。CD 样例中连续槽为 0.8349 nm，随机记录点为 0.8342 nm，半径向孔径为 1.6724 nm。另用 `--disc DVD --radial-mm 0.5 --tangential-mm 0.025 --seed 42` 复算，三个对应值为 0.7719、0.7712、1.5438 nm。

对齐的 DVD 0101 和 0100 分别有一对位于切向 ±47.4°、±21.6° 的一阶副峰。在径向 +1 级中心，单个副峰的强度分别为连续槽中心峰的 10.13% 和 5.07%。0101 的各轨道随机错相后，同一坐标的副峰降到 0.0038%，但图右仍能看到相同切向频率附近的功率，因为这部分光分散到了其他径向频率。右图是对一个径向空间频率周期积分后得到的切向功率分布，用于看能量去向；传播范围标在径向 +1 级中心对应的方向上。它是空间频谱诊断，不能直接读作相机上的绝对效率。

## 模型与解释

将照明区域内的螺旋局部展开为等间距直轨，取一条轨道上的复反射系数差为常量。远场振幅是各轨道贡献的相干和：

```text
A(qx, qy) ∝ Σ_j exp(−2πi qx j d) ∫ mask_j(y) exp(−2πi qy y) dy
```

`qx`、`qy` 是径向和切向空间频率，单位是 μm⁻¹，`mask_j` 表示第 j 条轨道上哪些位置具有记录点反差。代码用 FFT 计算切向积分，并用 sinc 因子包含每个矩形 T 单元的有限长度。均匀基底的镜面项省略，轨道横向形状的衍射包络在主峰附近视为常量。

- 当 `qy = 0`，每条轨道只留下该段的平均占空比。同样的占空比遍布整个径向孔径时，场的相干和只乘一个系数。占空比为 1/2，中心强度乘 1/4。线宽仍由径向有效照明轨道数 N 决定。均匀孔径的理论等效 FWHM 约为 `0.886 λ/N`，与连续槽的数值结果一致。
- 周期为 P 的沿轨重复图案在 `qy = ±1/P` 等处产生副峰。对齐时各轨道在副峰方向也可相干相加，错相时和会减小。随机游程则通常把部分功率铺成较宽的背景。
- 若一整片径向轨道的平均反差被压低，径向有效孔径会缩小或加窗。半径向孔径是这个机制的对照。信号变弱和背景上升还会影响弱谱线能否识别，即使 FWHM 基本相同。

这里的 0101 和 0100 是实体坑/台图案，每字对应 3T，周期分别是 6T、12T。两者同时改变了周期和占空比，各自与同占空比的对照一起读。DVD-ROM 标准还包含编码、NRZI 转换和同步字，随机案例只保留常规 3T–11T 游程数量级，未执行完整编码，也未声称模拟任意具体文件。常见染料刻录盘的记录标记来自记录层光学性质变化，可擦写盘使用相变材料；实际刻录盘的预刻槽还可能本身产生衍射。若用此模型比较同一张刻录盘的空白区域和已写区域，需把连续预刻槽和记录标记作为两个复振幅项叠加，并由测量约束各自的幅值和相位。这里的 25% 和 6.25% 只相对于同反差连续槽，不能作为实盘亮度或绝对效率。

本模型还省略盘面曲率、真实坑宽和深度、折射率、多层膜、偏振、狭缝宽度和相机像差。输出给出记录点图案单独贡献的理想线形，适合和原有的盘面几何模型并列比较。实验上可固定同一照明孔径、入射角和曝光，分别测窄谱线的 FWHM、主峰积分信号和谱带旁的背景。
